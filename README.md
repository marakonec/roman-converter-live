# Конвертер римських чисел

Консольна програма: переводить число в римський запис. Працює з числами від 1 до 3999.

## Як зібрати

Відкрити `roman-converter-live.slnx` у Visual Studio 2026 і натиснути `Ctrl+F5`.

## Що вміє

- перетворює число в римський запис;
- відхиляє числа поза межами 1–3999.

## Автор

Навчальний проєкт дисципліни «Професійна практика програмної інженерії», кафедра КІТ УДУНТ.
